# Header
Sticky frosted site header: serif logo, pill nav, round icon buttons and a cart count. Once the page scrolls it lifts into a floating pill.

Height `{header-h}` (80px); background `{header-bg}` with a 14px blur. The active nav link uses `{accent}`; hover shows a `{bg-soft}` pill that slides between links. Round buttons are 46px with a `{line}` border; the cart count is a `{primary}` badge. Scrolled state: width `100% - 24px`, 999px radius, `{line}` border. Consumer provides links and the theme toggle.
