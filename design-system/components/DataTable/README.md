# DataTable
Bordered table for per-lot tests and key-value spec lists.

Wrapper: 1px `{line}` border, `{radius-lg}` corners, `{surface}` fill, scrolls horizontally. Lot table headers: 12px uppercase 0.08em `{muted}` 600; cells padded 14x18px with `{line}` row rules. Spec table: label column 42% `{muted}`, values 600.
