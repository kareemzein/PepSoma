# CoaWindow
Browser-style window showing a live lot test: purity, chromatogram placeholder, pass rows.

Window: `{surface}`, 1px `{line}`, 18px radius, `{shadow-lg}`. Title bar on `{bg-soft}` with three `{line-2}` dots and a pill URL in `{faint}`. Purity numeral is Fraunces italic 38px. Rows on `{bg-soft}` with a `PASS` pill that turns `{success}` tint once the test animates in. Decorative; the real data lives on lot pages.
