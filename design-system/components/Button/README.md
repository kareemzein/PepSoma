# Button
Pill-shaped action. Primary (navy, inverts in dark) for the main action, secondary (lavender) beside it, ghost for tertiary, yellow for the single highlight CTA per page.

Use `.btn` + `.btn-primary|secondary|ghost|yellow`, sizes `.btn-sm` (8/14px) and `.btn-lg` (18/30px), `.btn-block` for full width. Hover lifts 1px; primary adds a `{glow}` shadow. Disabled shows a spinner and 0.7 opacity. Consumer provides the label in sentence case.
