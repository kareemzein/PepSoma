# MarqueeChip
Compound chip used in the scrolling band: bold name, muted category, colored dot.

Pill, 10x16px, `{surface}`, 1px `{line}`, 14.4px; name 700, category `{muted}`, 8px dot. Hover lifts 2px and darkens the border to `{text}`. The band scrolls 48s linear, reverse rows 56s, pauses on hover, and fades at both edges.
