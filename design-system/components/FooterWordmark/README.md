# FooterWordmark
Giant decorative wordmark that closes the footer.

Fraunces italic 500, clamp(96px, 22vw, 320px), leading 0.8, tracking -0.05em, color `{wordmark}` (6% navy in light, 5% white in dark). Decorative: no pointer events, hidden from selection. Sits on `{bg-tint}` and is cropped by the page bottom (-0.14em bottom margin).
