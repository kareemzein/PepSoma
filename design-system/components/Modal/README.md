# Modal
Centered dialog on a dimmed backdrop, used for the age gate and lot COA viewer.

Backdrop rgba(10,6,25,.45). Panel `{bg}`, `{radius-lg}`, 36px padding, max 560px, deep shadow; enters with 12px rise and 0.98 scale over 0.22s. Close button is a 38px round `{surface}` button top-right. Trap focus and restore it on close; consumer provides content.
