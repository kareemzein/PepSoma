# CartLine
One line item in the cart drawer or cart page: thumbnail, name, meta, stepper and price.

Grid 72px / 1fr / auto, 14px gap, `{line}` bottom rule. Thumb 72x84 on `{surface-2}`, `{radius}` corners. Name 700 15px; meta 12.8px `{muted}`. Struck-through original price in `{muted}`; remove button turns `{danger}` on hover. Consumer provides product data and handlers.
