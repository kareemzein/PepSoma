# Toast
Transient confirmation pill at the bottom of the screen.

Pill, 12x18px padding, `{primary}` fill with `{primary-text}` (or `{danger}` with white for errors), 14.4px 600, soft shadow. Slides up 12px on enter over 0.25s; centered 24px from the bottom; ignores pointer events. Consumer provides copy and auto-dismiss.
