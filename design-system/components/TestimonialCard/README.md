# TestimonialCard
Frosted quote card on the navy testimonial band.

Sits on a navy gradient band (literal `#14215a` to `#2c43a0`, same in both themes). Card: white 10% fill, 16% white border, 10px blur, `{radius-lg}`. Stars `{yellow}`; title 17.6px 700 white; quote 15px at 85% white; caption 13px at 70%. Hover lifts 4px.
