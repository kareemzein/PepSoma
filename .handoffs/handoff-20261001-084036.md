## Review mode (`store/js/review.js`, one IIFE, vanilla JS)
- **On/off:** per tab (sessionStorage `pepsoma.review`). Turned on by `?review` or `/review/`. "Exit review" turns it off.
- **Modes:** Browse / Comment.
  - Comment mode swallows clicks and outlines on hover, Chrome-inspect style. Clicking opens a comment box; Bigger ↑ / Smaller ↓ change the selection.
  - Each comment gets a numbered pin, tracked by a CSS-path selector.
- **Names:**
  - The picker asks on first use; names are kept per device.
  - **N** / Shift+N cycle names, with a mid-screen switcher like the Mac language switcher.
  - × takes a name off the list but keeps its comments. A separate "Delete one person's comments" box does the deleting.
  - Each person gets a color.
- **Keys:** C toggle, F whole-page comment, B browse, N person, **S slow motion**, **?** guide, Esc, ⌘↵ save.
- **Show/hide people:** clicking a name chip in the Comments panel toggles that person everywhere, in both views. It's stored in `reviewHidden`. The bar shows "Hiding: Name ×".
- **Sheet sync:**
  - Every new, edited, done or deleted comment POSTs to the Apps Script as `text/plain`. Rows are upserted by `id`; deletes are tracked in `reviewGone`.
  - It retries when offline.
  - If the response can't be read cross-site, it falls back to a `no-cors` send. The real script allows CORS, so the normal path is used.
- **Everyone (sheet) view:**
  - Read-only comments from all laptops. It sends a POST `{list:true, key}`, and the script checks `ADMIN_KEY`.
  - The tab remembers the password (sessionStorage `pepsoma.reviewKey`). A **Lock** button clears it.
  - The old open `GET ?list=1` was removed and now only returns the health text.
  - Rows from other origins (e.g. localhost tests) are ignored.
- **Slow motion (S):**
  - Store animations run at ¼ speed through `playbackRate`, re-applied every frame.
  - `performance.now`, rAF timestamps, `setTimeout` and `setInterval` are patched to a virtual clock. Review mode's own timers use the saved originals `later` and `frame`.
  - Known gap: the rotating headline's `setInterval` starts before review.js loads, so its cadence isn't slowed.
- **Welcome guide:** shown on first visit per device (`reviewWelcomed`), with four steps and looping CSS demos. Then the name picker. Reopened with **?** or "How it works".
- **Storage keys** (localStorage, prefix `pepsoma.`): `reviewNotes`, `reviewGone`, `reviewPeople`, `reviewWho`, `reviewColors`, `reviewHidden`, `reviewSource`, `reviewWelcomed`. sessionStorage: `pepsoma.review`, `pepsoma.reviewKey`, `pepsoma.reviewSlow`.

## Key decisions and why
- **No /admin/ page.** Everything lives inside review mode; the sheet view is the "admin" view, behind a password.
- **Anyone can add comments** (Kareem: "that's the design"). Only reading everyone's comments needs the password.
- **The password lives only in Apps Script script properties**, because the repo is public. It's sent in a POST body, not a URL.
- **The password isn't on the hub or the deck**, since either may be shared. The hub says where to find or change it.
- **Kareem uses Arc**, so artifact links use `target="_blank"`.

## How to verify (rebuild in your scratchpad if it was wiped)
- Use headless Chrome over CDP with Node 26; there's no Playwright. Helpers: `cdp.mjs`.

  - `/acao/on` adds the CORS header to its 302.
