## How to verify (rebuild scripts as needed; scratchpad gets wiped)
- **Driving Chrome:** there's no Playwright. Drive headless Chrome over CDP with Node 26: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --remote-debugging-port=9333 --user-data-dir=<fresh tmp dir>`. Wait until `curl localhost:9333/json/version` responds.
- **Setting up storage:** to set localStorage before a page loads, navigate to a **renderable** file on the same origin, like `store/favicon.svg`. **Never use a .md file**: Chrome downloads it to ~/Downloads (see memory `headless-chrome-no-downloads`).
- **Storage keys:**
  - Skip the store's age gate and cookie banner with `pepsoma.ageOk` and `pepsoma.cookies`.
  - Skip feedback onboarding with `pepsomaWelcomed=1`.
  - Dismiss title cards with `#tcGo`.
- **Testing the deploy:** extract the `run: |` block from `pages.yml`, run it with bash in a temp copy, and serve `_site` under a `/PepSoma/` folder.
- **zsh gotcha:** `$var` lists don't word-split in loops; use `while read`.
