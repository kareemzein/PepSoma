# Handoff — Pepsoma storefront MVP (2026-09-23)

## Goal
Build the website for **Pepsoma** (pepsoma.com), a new US research-use-only (RUO) peptide company, as a working demo on GitHub. Two design directions were built for the owner to choose from. The owner leans toward **Version A** (the one modeled on brellohealth.com) and cares a lot about **design and interactivity (animations)**. The next session will most likely keep polishing Version A.

## Current state
- Repo: `kareemzein/PepSoma`. Work branch `claude/zen-ride-4rq277`. **Merged into `main`** (fast-forward, head `35674c8`).
- Static site with no build step. Hash routing; all state in `localStorage` (cart, orders, accounts, theme). Runs with `python3 -m http.server`.
- `.github/workflows/pages.yml` deploys on push to `main`. **The owner still has to enable Settings → Pages → Source: GitHub Actions.** No `CNAME` yet on purpose: it would redirect the github.io URL before DNS is ready.
- Live previews (private artifacts owned by the user, built as single-file bundles of each version):
  - Version A “Clinical”: https://claude.ai/artifact/8qJ28tdo65vMh1GVNA2T89
  - Version B “Lab”: https://claude.ai/artifact/J5MJJKoG85VByCbLNyXMoc
  - Reference board (8 competitor sites with notes): https://claude.ai/artifact/5vtLuGqz914CTpPKdd9VHa

To refresh a preview, rebuild the bundle and republish with the Artifact tool using `url` = the artifact link.
- Verified: an end-to-end Playwright flow passes on both versions with no JS errors. It covered age gate → product (size, plan, qty) → cart → promo codes → checkout validation → order → tracking → signup/signin → cancel standing order → COA modal → contact → 404 → search. No horizontal overflow at 390px.

## Architecture (read the code, don't guess)
- `index.html`: split-screen chooser (A | B).
- `shared/js/data.js`: company info (`PS.company`, bracketed placeholders), categories, 16 products + 4 stacks, FAQs, steps, **sample** testimonials.
- `shared/js/core.js`: storage, `PS.config` (free shipping at $150, shipping methods, standing-order plans 15%/10%, volume tiers 3+/5+/10+ vials, promo codes WELCOME10 / LAB15 / SHIPFREE), cart totals, orders (demo status timeline in minutes), accounts (SHA-256 hashed passwords stored locally), validation, hash router.
- `shared/js/visuals.js`: SVG vials (`PS.vial`, themes `light` | `dark`), lots and COA data (demo, watermarked “SAMPLE DATA”), chromatogram.
- `shared/js/policies.js`: 9 policies (Terms, Research Use Only, Shipping, Refunds, Testing & COA, Standing Order / auto-renew, Privacy, Cookies, Accessibility). Templates only; need legal review.
- `shared/js/ui.js`: icons, form components, default pages (order, track, labs, faq, contact, wholesale, account, policies, 404), modal/drawer/toast, delegated behaviors, `PS.boot(theme)`. Hooks: `theme.afterRender(route, main)`, `theme.cartDelay`, and a `PS.emit('added', {el})` event.
- `shared/css/base.css`: shared structure driven by CSS variables.
- `a/` and `b/`: each has `index.html`, `app.js` (header, footer, drawer, summary, pageHead, gate, cookie banner, home / shop / product / cart / checkout / about) and `styles.css`.
- `<html>` attributes: `data-site="a|b"` marks the version. `data-theme="light|dark"` is **only** the light/dark override, which the artifact host also uses.

## Key decisions and why
- **RUO business model** (like olympexsolutions.com), not telehealth (Brello), for both versions. Telehealth would need prescribers plus HIPAA and telehealth-consent policies. Checkout requires attestations (21+, not for human/animal use, terms, auto-renew).
- **GLP-1s left out** (semaglutide, tirzepatide, retatrutide) because the FDA is actively going after RUO sellers of them. The owner can add them in `data.js`.
- **Vial labels** show only brand, name, size and purity. The owner asked to remove the lot number and the “Research use only” text from the bottles.
- **Version A follows the device's light/dark setting.** A sun/moon/system toggle in the header (plus a segmented control in the footer) overrides it. The choice is stored in `pepsoma.mode` and applied before paint by an inline script in `a/index.html`. Theme switches use a View Transitions circular reveal. None of the 11 reference sites checked follow device dark mode, so this sets Pepsoma apart.
- **Motion for Version A** borrowed from the owner's **USMLE Reframe design lab** (artifact https://claude.ai/artifact/DjmbxEay1ciFEaifYyWDqx, “Feather” blueprint + “Inspiration Lab” boxes 01–08):
  - rise-and-unblur staggered load-ins that replay on each page
  - a sliding nav pill
  - a rolling headline word
  - parallax on the hero art
  - a marquee of compound chips
  - count-up stats
  - a live COA “browser window” that draws a chromatogram and passes each test, looping while visible
  - card tilt with a spotlight
  - fly-to-cart
  - a corner-bracket closing section
  - a giant footer wordmark

  Everything respects `prefers-reduced-motion`. Fonts stay Fraunces + DM Sans; the Reframe lab uses Newsreader.
- Demo data is labeled honestly: testimonials are marked as samples, COAs are watermarked, and the footer says “Demo storefront”.

   - Version A opens the cart drawer about 560 ms after an add, so tests must wait for it.
