## How to verify (same method as the last handoff)
- **Driving Chrome:** run headless Chrome over CDP (`--headless=new --remote-debugging-port=… --user-data-dir=<fresh>`) with a Node 26 `.mjs`.
- **Setting up storage:** first navigate to `store/favicon.svg` to set storage. **Never use a .md file**: it downloads to ~/Downloads.
  - Keys: `pepsoma.ageOk`, `pepsoma.cookies`.
  - Clear `sessionStorage` so the opening plays.
- **Close-ups:** for the opening, use `Page.captureScreenshot` with `clip`, where size = 64·max(w,h)/1000·1.6 centred, at `scale: 4`.
- **Timing:** frame times run about 100–400ms behind their labels because of capture overhead.
- **Deploy check:** after a push, `gh run watch`, then `curl` the live file with a cache-buster to confirm.
