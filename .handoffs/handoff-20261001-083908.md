## The store opening (final)
Code locations:
- `store/index.html`: a head script.
- `store/styles.css`: the block that starts `/* opening (first visit in this browser only)`.
- `store/app.js`: `(function opening(){…})()` at the bottom.

How it plays:
1. **When:** only the **first time the site is opened in a browser** (`localStorage 'pepsoma.opened'`). On later visits, nothing plays: no opening and no short version (Kareem's choice). It's skipped under reduced motion, and a tap skips ahead.
2. **Cover:** matches the page (cream in light mode, dark navy in dark).
3. **Trace:** two halves of the outline start together at the **bottom centre** and trace up both sides, meeting at the top. There's no seam or start dot (round caps, `pathLength 100`, dasharray `100 110`, dashoffset `101→0`). The line is `var(--text)` while tracing, then turns navy.
4. **Fill:** the navy fill blooms, the yellow italic "p" rises in, then "Research-grade peptides / pep*soma*" fades up.
5. **Fly-through:** at **3000ms**, the mark flies past as a ring while a mask hole opens onto the page and its entrance animation replays. The cover is gone at about 4.25s.
6. **Safety net:** if `app.js` never takes over, the head script lifts the cover after 4s, so the store can't get stuck hidden.

Rejected along the way, so don't re-propose these:
- A single stroke from the top-left that showed a seam
- A plain fade-in ("underwhelming")
- Split from the top
- One clockwise line from the top-left corner
- A soft glow under the line (added, then removed)
- Replaying once per tab

## How to verify
- **Chrome:** run headless Chrome over CDP with a Node 26 `.mjs`, using your own ports and a fresh `--user-data-dir`.
- **Waiting in scripts:** use `awaitPromise: true` when evaluating promises. Without it, "wait for the cover" doesn't wait, and you'll misread the page.
- **Setting storage:** navigate to `store/favicon.svg` first. **Never use a `.md` file**: it downloads to ~/Downloads.
  - Keys: `pepsoma.ageOk`, `pepsoma.cookies`.
  - Clear `localStorage` to see the opening.
- **Accurate animation frames:** pause animations with `document.getAnimations().forEach(a => { a.pause(); a.currentTime = t })`. Screenshots with `clip` + `scale: 4` give close-ups.
- **Multi-tab behavior:** open tabs with `PUT /json/new?<url>`.
- **After a push:** `gh run watch`, then `curl` the live file to confirm.
